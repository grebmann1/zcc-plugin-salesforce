# Agentforce Studio V3 — continuous app edit

**00:00:00** How to build an Agentforce agent in Zana.

**00:00:03** Use Pi with the SF-Pi plugin. It builds, previews, and tests the agent for you.

**00:00:11** Start a thread on the Pi harness, in your Salesforce project, and describe the agent you want.

**00:00:19** Pi plans it, writes the Agent Script, and compiles it, right in the thread.

**00:00:24** It hands back a card for the new agent.

**00:00:26** Click it, and the agent opens beside the thread: the script, and its conversation graph.

**00:00:33** Ask what the return window is. Pi previews the agent and links the run.

**00:00:39** The run opens in the same panel. Fourteen days. Our policy is thirty.

**00:00:44** Ask for thirty days, and five test scenarios. Pi edits the file, then writes the scenarios itself.

**00:00:52** Open it again, and the script reads thirty.

**00:00:55** Pi runs the five scenarios as simulated customers, four at a time. Five of five pass.

**00:01:01** Check it yourself, right in the panel: thirty days.

**00:01:08** When you want the full workbench, open it in Agentforce Studio: the same script, thirty days and all.

**00:01:15** Every action is one click away, like the return Flow, drawn as its real canvas.

**00:01:21** And the Lightning Type the order lookup returns, with the card that renders it.

**00:01:26** Here's a separate test run with a failing return policy. Ask the agent to improve it.

**00:01:32** Two pass. The judge shows exactly why the return policy failed.

**00:01:37** Ask it to improve the failing one. It tests every attempt against the same batch, without touching your file.

**00:01:48** Baseline two of three. Best, three of three.

**00:01:51** You review the change as a diff. Accept it, and save.

**00:01:56** Ask it to check again: thirty days. And the batch now passes, three of three.

**00:02:02** Your editor can evolve, too. Ask your coding agent to add a missing editor tool.

**00:02:08** It updates the editor, checks the change, and reloads the plugin in place.

**00:02:13** The export tool appears in the toolbar. No reinstall.

**00:02:17** Click it to export this agent's diagnostics, including its test results.

**00:02:22** Keep working in the same editor, with the new tool ready to use.
